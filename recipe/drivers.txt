// This is a MAME "driver filter" file (make SOURCEFILTER=…): one source file per line, relative to
// MAME's src/mame/, with every system that file defines (the parent games and their clones). C++
// comments are allowed. A line "+name" adds a single system, "-name" leaves one out.
// Each file pulls in the CPUs, sound chips and cartridge/slot devices it needs, so a line can add
// a lot: the build's manifest.json lists every system that ended up in it.
// After changing this file, run tools/mame/build.sh again (and bump RECIPE there).
